# MP4 → MP3

Скрипты для преобразования локального MP4 в MP3. В MP3 встраивается обложка из кадра видео. Если в описании файла есть таймкоды, запись разделяется на отдельные треки; иначе создаётся один MP3 целиком.

## Какие программы нужны

[FFmpeg](https://ffmpeg.org/) выполняет преобразование звука и извлекает обложку. В его комплект входит `ffprobe` для чтения метаданных видео.

В проекте два варианта запуска — достаточно одного:

- `split-music.ps1` — для Windows, с выбором видео через окно. Python не требуется.
- `split_music.py` — для macOS, с передачей пути к видео в Терминале. Для запуска нужен Python 3. Этот вариант также работает в Windows.

Интернет нужен для установки программ. Само преобразование выполняется локально.

## Windows: от установки до MP3

### 1. Установка FFmpeg

Открыть **Windows PowerShell** через меню «Пуск» и выполнить:

```powershell
winget install --id Gyan.FFmpeg -e --source winget
```

Используется [сборка FFmpeg от Gyan](https://www.gyan.dev/ffmpeg/builds/). Если команда `winget` отсутствует, установить или обновить [App Installer из Microsoft Store](https://apps.microsoft.com/detail/9nblggh4nns1).

После установки закрыть PowerShell, открыть заново и проверить:

```powershell
ffmpeg -version
ffprobe -version
```

Обе команды должны вывести информацию о версии.

### 2. Подготовка файлов

Скачать проект и распаковать архив. Подготовить исходное видео в формате MP4 — оно может находиться в любой папке.

В Проводнике открыть папку со скриптом `split-music.ps1`, ввести `powershell` в адресной строке и нажать Enter.

### 3. Преобразование

В открывшемся PowerShell выполнить:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\split-music.ps1"
```

В окне выбора файла указать MP4. После завершения автоматически откроется папка с готовыми MP3 рядом с исходным видео.

Обложка берётся на отметке **01:30**, поэтому для этого варианта видео должно быть длиннее 90 секунд.

## macOS: от установки до MP3

### 1. Установка Homebrew

[Homebrew](https://brew.sh/) — менеджер пакетов для установки FFmpeg и Python. Описанный способ рассчитан на macOS 15 и новее.

Открыть **Терминал** через Spotlight (`⌘ + пробел` → «Терминал») и выполнить команду с сайта Homebrew:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Следовать инструкциям установщика. Он может запросить пароль учётной записи macOS и установку Apple Command Line Tools. При вводе пароля символы не отображаются.

После установки выполнить команды из раздела **Next steps** в выводе установщика — они добавляют Homebrew в `PATH`, чтобы команда `brew` работала в Терминале.

### 2. Установка FFmpeg и Python

```bash
brew install ffmpeg python3
```

Пакеты: [FFmpeg](https://formulae.brew.sh/formula/ffmpeg) и [Python](https://formulae.brew.sh/formula/python3). Дополнительные Python-библиотеки не нужны.

Проверка установки:

```bash
ffmpeg -version
ffprobe -version
python3 --version
```

Все три команды должны вывести информацию о версии.

### 3. Подготовка файлов

Скачать проект и распаковать архив. Подготовить исходное видео в формате MP4.

В Терминале ввести `cd ` с пробелом, перетащить папку проекта из Finder в окно Терминала и нажать Enter. Так текущей папкой станет каталог со скриптом `split_music.py`.

### 4. Преобразование

Выполнить команду с путём к видео:

```bash
python3 split_music.py "/Users/user/Movies/video.mp4"
```

Путь в примере заменяется фактическим. Вместо ручного ввода можно набрать `python3 split_music.py ` с пробелом, перетащить MP4 из Finder в Терминал и нажать Enter.

После завершения папка с готовыми MP3 автоматически откроется в Finder.

По умолчанию обложка берётся на отметке **01:30**. Для короткого видео или другого кадра время задаётся в секундах:

```bash
python3 split_music.py "/Users/user/Movies/video.mp4" --cover-time 10
```

Для сохранения записи одним MP3, даже при наличии таймкодов:

```bash
python3 split_music.py "/Users/user/Movies/video.mp4" --whole
```

Параметры `--whole` и `--cover-time` можно использовать вместе.

## Результат

Рядом с исходным MP4 создаётся новая папка `Tracks_дата_время`, содержащая:

- один MP3 целиком или отдельные MP3 по трекам;
- `cover.jpg` — кадр, который также встроен в каждый MP3.

Исходное видео сохраняется. Каждый запуск создаёт отдельную папку результата.

## Разделение на треки

Для разделения нужны как минимум два таймкода в метаданных MP4: `description` или `comment`. Пример содержимого:

```text
00:00 Artist - First Song
05:12 Artist - Second Song
```

Поддерживаются часы (`01:02:30`), время в квадратных скобках и нумерация перед названием. Таймкоды должны идти по возрастанию и находиться в пределах видео.

Таймкоды на странице, откуда скачано видео, не всегда сохраняются внутри MP4. Если подходящего списка в самом файле нет, скрипт создаёт один MP3 без разделения.
